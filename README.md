## 复现

推荐 Python 3.11、Blender 5.1、FFmpeg，另安装 `requirements.txt`。在解压目录新建自己的虚拟环境。已附男声WAV，重剪使用这些音频即可；修改文案后可用自己的 Vertex AI 项目重新生成。

```powershell
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt
.venv/Scripts/python reproduce.py --blender "C:/Program Files/Blender Foundation/Blender 5.1/blender.exe"
.venv/Scripts/python reproduce.py --run --blender "C:/Program Files/Blender Foundation/Blender 5.1/blender.exe"
```

首条reproduce命令只检查输入，`--run` 按保存参数重跑七组动力学、四组补充实验、Blender场景、镜头渲染、音画合成和验收。请在副本中运行，输出会覆盖同名生成文件。建模与渲染需要可用的Blender图形后端。

默认使用Windows微软雅黑与NVIDIA编码。其他环境将 `M9_FONT_REGULAR`、`M9_FONT_BOLD` 指向中文字体文件，设 `M9_VIDEO_ENCODER=libx264` 可使用CPU编码。Blender路径可通过 `BLENDER_EXE` 设置。不同平台未做逐一验收，按预检错误补齐依赖。

## 从原帧到速度点

原片零起始帧号，时间为帧号/30。344至393帧跨49个帧间隔，共1.633333秒。重复曝光和重复画面保留在时间轴内。

`assets/observations.json` 保存逐帧尾灯下缘y；x与宽度是ROI锚点插值。`scene_calibration.json` 保存条件相机尺度。简化纵深反算为Z=K/y，K约17190.38，y0=0。同一特征352帧y=369、357帧y=327，纵深分别46.586m、52.570m；5.984m/0.166667s×3.6约129.25km/h。

青色点是五帧窗口的纵深差分，金线是MuJoCo的瞬时水平速度。转弯行程由二维运动累计。`速度推导逐帧表.csv`、`逐点动画计算.json`、`速度推导计算.json`可以追溯屏幕数字，`calculate_speed_workings.py`与`motion_speed.py`负责复算。

米尺来自候选车顶边界间距2.70m，换算到尾灯高度；边界偏移±6px时尺度约变化−21%/+34%。卫星图A—B约56m、C—D约32m保留自己的端点，进一步定尺需要与视频地面地标对应。

基准初速约135、344—393帧均速约126、路缘接触约112、主柱接触约100km/h，均属于这套尺度与参数的计算。原拟合初速搜索范围108—165.6km/h，见 `physics.py`。60/80固定输入对照之外，还可以另建实验，联合重新估计相机尺度、制动和转向。

## 输入与接触结果

基准质量2650kg、轴距3.11m，MuJoCo 3.16.0、步长1/600秒、30fps输出。四轮刚体接触、悬架、制动扭矩、转向关节、空气及滚动阻力参与求解。位置与接触后姿态由积分生成。轮胎接触和滑移控制采用通用简化参数，车辆外形是M9尺寸级模型。

以下用时从第344帧（11.466667秒）起算；主柱与细柱分别保存。

| 假设 | 首次路缘接触：用时/速度 | 首次主柱接触：用时/速度 |
|---|---|---|
| 基准物理假设 | 1.592 s / 112.0 km/h | 1.643 s / 100.4 km/h |
| 提前0.35秒制动 | 1.718 s / 98.6 km/h | 1.770 s / 88.6 km/h |
| 晚0.35秒制动 | 1.553 s / 120.0 km/h | 1.573 s / 109.2 km/h |
| 较低附着 μ=0.55 | 1.503 s / 116.7 km/h | 计算区间内未接触 |
| 较弱制动力 | 1.580 s / 117.3 km/h | 1.603 s / 107.2 km/h |
| 路缘高10厘米 | 1.593 s / 112.0 km/h | 1.642 s / 106.8 km/h |
| 路缘高22厘米 | 1.575 s / 112.3 km/h | 计算区间内未接触 |

初速60与80实验保持其余输入，分别在约2.77秒/26.81m与3.57秒/45.01m降至持续低于0.5km/h，两组未接触障碍。

主柱40/50实验从基准第390帧（13.000秒）状态重启，保持转向、释放制动、缩放初始速度。进入速度46.30/56.96km/h，经过0.271667/0.220000秒接触主柱，事件速度40.001/50.000km/h。这是最后一小段的局部比较。每个接触速度与对象见 `contact_ledger.json`；画面按30fps取最近渲染帧，数字按求解器事件时刻。

路缘基准高16cm、人行道宽4m、主柱位置与相机配准是场景输入。后拍照片提供形态线索；车体压溃、结构断裂和燃烧未建立材料模型。半步长检查见 `physics_validation.json`，碰撞后姿态存在数值敏感性。原片第394—396帧出现异常姿态，首次接触的具体部位仍受遮挡。
